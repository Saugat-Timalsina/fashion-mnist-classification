# Fashion-MNIST Classification Using CNN

This project classifies Fashion-MNIST clothing images using a custom convolutional neural network built with TensorFlow and Keras.

## Dataset
- 60,000 training images
- 10,000 test images
- 10 clothing categories

## Architecture
- Five convolutional layers
- Batch normalization
- Dropout regularization
- Dense classification layers
- Adam optimizer

## Results
- Best validation accuracy: 95.03%
- Test accuracy: See notebook results

## Technologies
Python, TensorFlow, Keras, NumPy, Matplotlib, Jupyter Notebook
